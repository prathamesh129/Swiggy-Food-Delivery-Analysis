# Swiggy Food Delivery Analysis

## Project Overview

A data analysis project using **SQL and Power BI** to analyze food delivery performance, customer behavior, restaurant performance, order trends, and delivery status using sample food-delivery data.

The project includes SQL-based analysis and an interactive Power BI dashboard designed to provide clear business insights.

## Tech Stack

- MySQL
- MySQL Workbench
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV Dataset

## Data Source

The project uses a **sample food delivery dataset** containing information related to:

- Orders
- Customers
- Restaurants
- Deliveries
- Order items

The dataset was used for SQL analysis and Power BI dashboard development.

## Project Objectives

- Analyze overall order and revenue performance
- Identify top-performing cities
- Identify top restaurants by revenue
- Analyze popular dishes
- Analyze high-spending customers
- Analyze delivery performance
- Understand monthly order and revenue trends
- Build an interactive business dashboard

## SQL Analysis

SQL was used to perform:

- Aggregation and grouping
- Joins between multiple tables
- Subqueries
- Window functions
- Ranking analysis
- Customer spending analysis
- Restaurant revenue analysis
- Order and delivery analysis
- Business-focused queries

## Key Insights

- Total revenue: **₹3.23M**
- Total orders: **10K**
- Total deliveries: **9.75K**
- Average order value: **₹322.82**
- Total restaurants: **61**
- Mumbai generated the highest revenue among the displayed cities.
- The dashboard identifies the highest-performing restaurants, dishes, and customers.
- Monthly analysis shows changes in order volume and revenue throughout the year.
- Delivery status analysis highlights the overall delivery performance.
